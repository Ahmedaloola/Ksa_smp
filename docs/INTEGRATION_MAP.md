# KSA SMP — خريطة ربط الإضافات

## المصدر الرئيسي للسلوك

- **KSASMP:** Shop/AH/Orders/Shards/Scoreboard حسب الإعدادات الحالية.
- **Vault:** API فقط، وليس اقتصادًا مستقلًا.
- **PlaceholderAPI:** عرض قيم الإضافات بعد تثبيت expansions المطلوبة.
- **Essentials:** أوامر عامة وSpawn/Home/Kits حسب عدم تعارضها مع KSASMP.

## قواعد عدم التكرار

- لا نستخدم ClearLag وWildStacker لحذف نفس الكيانات دون اختبار مشترك.
- لا نستخدم Chunky وChunkManager للتوليد المسبق في الوقت نفسه.
- لا نفعّل اقتصاد Essentials بالتوازي مع اقتصاد KSASMP قبل تحديد المصدر.
- لا نستخدم نظام GUI ثانٍ لنفس `/shop` أو `/scoreboard` دون اختيار صريح.
- لا نضيف DiscordSRV أو Bot جديدًا قبل تحديد سبب الحاجة والصلاحيات.

## اختبار كل ربط

لكل تكامل نتحقق من: بدء التشغيل، غياب أخطاء `UnknownDependency`، صلاحيات لاعب عادي، لاعب Bedrock، مخزون ممتلئ، كمية غير صالحة، وإعادة التشغيل الكامل.
